# 📉 Agent IA Boursier (Streamlit)

Suivi automatique des actions Sanofi, Airbus, Teleperformance, etc.  
Affiche les variations boursières et les dernières actualités via Boursorama.

## ✅ Fonctions
- Suivi de 6 actions avec seuils d'alerte (-3, -5, -7 %)
- Récupération automatique des titres d'actualités depuis Boursorama
- Interface simple (1 clic) via Streamlit

## ▶️ Lancer l'application localement

```bash
pip install -r requirements.txt
streamlit run app.py
